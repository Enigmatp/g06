1
宠物选择页
全屏 · 入口页面
顶部标题栏
左侧「基因变异」渐变标题，右侧显示💎当前持有基因碎片数量
引导文字
「选择一只15阶宠进行基因变异」— 简洁操作引导
5列宠物网格
每张卡片：金色圆环 + emoji + 名称 + 3个突变进度dot。所有宠物统一金色品质（全部15阶），无品质字母标记
★星级标记
已提纯的宠物右上角显示当前星级（如 ★10）
状态标签
右下角显示宠物状态：出战（红）/ 🔒锁定（黄）/ 镶嵌（紫）
返回按钮
左下角「‹ 返回」退出变异系统
同名宠物逐一独立显示（如6只烈焰龙王），因为每只是独立资产，需被消耗作为突变材料

详情弹窗 · 基因提纯
居中弹窗 · z-index:50
弹窗定位
垂直居中，四边圆角，毛玻璃遮罩背景
Header区
彩虹旋转圆环头像（conic-gradient动画）+ 宠物名 + 攻击类型Tag
🔓 锁定按钮
Header右侧，点击切换锁定/解锁状态，防止宠物被误消耗
碎片显示
右上角 💎12,800 — 实时显示当前碎片余额
星级总览
大号 ★0 + 属性继承百分比（每星+5%）
双Tab切换
「✦ 基因提纯」/「🧬 基因突变」— 激活项有蓝紫渐变高亮
数据卡片
当前星级 / 属性继承% / 升星消耗碎片 — 3行信息区
突变节点进度条
蓝→紫→金渐变进度条，10/20/30位置有刻度标记
提纯升星按钮
金色渐变大按钮，支持单击和长按连续升星
被动技能插槽
3个圆形插槽（初始全锁定🔒），通过突变逐步解锁
关闭按钮
底部居中圆形 ✕ 按钮，点击遮罩也可关闭
3
锁定/解锁操作
弹窗内交互
Toast提示
顶部滑入「烈焰龙王 已锁定」蓝色信息提示
锁定按钮变化
🔓 → 🔒 图标切换，按钮背景变为红色底色

锁定功能核心用途：保护宝贵宠物，防止在突变操作中被误消耗

技能镶嵌完成
闭环 · 最终状态
成功Toast

插槽显示

粒子效果

设计规范

弹窗定位

所有弹窗 / Modal 垂直居中显示，底部统一圆形 ✕ 关闭按钮

缩放方式

固定 390×693px 设计尺寸，通过 transform:scale() 整体等比缩放

品质标识

统一金色圆环（全部15阶S品），不显示品质字母

色彩体系

金色 = 提纯 紫色 = 突变 蓝色 = 镶嵌 红色 = 危险

反馈机制

Toast提示（顶部滑入）+ 粒子效果 + 圆环发光动画

层级结构

Layer 0: 全屏选择页 → Layer 1: 详情弹窗(z:50) → Layer 2: Modal(z:100)
