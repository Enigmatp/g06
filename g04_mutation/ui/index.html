3

1
阶段进度3个dot + 「pet.mutationLevel/3 阶段完成」。dot填充数=mutationLevel
2
阶段徽章 + 标题「一阶」紫色Badge + 「N阶突变 · 解锁插槽N」。取 STAGES[mutationLevel]
3
前置条件「提纯达到 stage.starReq★ (当前 pet.star★)」。绿=满足 / 红=不满足。三阶要求：10/20/30★
4
突变消耗「stage.petCost只 同名宠物」。三阶梯度 1→2→4。同名=相同 configId
5
材料行emoji + name + (可用/需要)。可用 = allPets.filter(同configId, idle, !locked, id≠主宠).length
6
执行突变按钮点击 → 打开确认弹窗。条件：star≥starReq && 可用材料≥petCost。否则灰色禁用
7
解锁状态图标🔓=条件全满足 / 🔒=条件不足
